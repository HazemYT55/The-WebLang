v1.0 · A simple, readable web language that replaces HTML, CSS and JavaScript with 3 clean file types.

🚀 Quick Start

A full interactive page in 3 tiny files:

# page.btw
link web.stw
link web.mtwc

title : My App
t.1 "Welcome" [id:1]
btn "Dark Mode" [id:2]
img: photo.jpg
# web.stw
body([t.a:center],[f.fa:Times],[c:white],[b.col:black])
# web.mtwc
btn.id = 2 , connect to 'page.btw':

action(Dark)
  inclick btn:
    if (Dark) == true:
      (Dark) == false
      theme light
    else
      (Dark) == true
      theme dark

🎨 STW · Style The Web

Extension: .stw · Replaces: CSS · Purpose: styles BTW elements using short property tags. Connect it with link web.stw in your .btw file.

The Rule · 3 Levels

Take letters from each word of the CSS property name, and pick the level with no clashes. Example: font-size

LevelRuleResult
1.11 letter per wordf.s
1.121 letter from word 1, 2 from word 2f.si
1.131 letter from word 1, 3 from word 2f.siz

Clash fixes: f.s means font-size, so font-style goes to 1.12 → f.st. Padding and position are both p → rename position to pos. Border-color clashes with background-color → use 1.13 b.col for both, or rename to bg.co / bd.co.

Order matters:

4Add [id:N] to any element MTWC needs to control
5In MTWC → connect to 'page.btw':

Dark Mode Toggle

# page.btw
link web.mtwc

title : My Page
t.1 "Welcome"
btn "Toggle Dark" [id:1]
# web.mtwc
btn.id = 1 , connect to 'page.btw':

action(Dark)
  inclick btn:
    if (Dark) == true:
      (Dark) == false
      theme light
    else
      (Dark) == true
      theme dark

Counter

# page.btw
link web.mtwc

title : Counter
t.1 "Count: 0" [id:5]
btn "+" [id:1]
btn "−" [id:2]
# web.mtwc
var count = 0
connect to 'page.btw':

btn.id = 1
action(Add)
  inclick btn:
    (count) == (count) + 1
    set t.1 "Count: (count)"

btn.id = 2
action(Sub)
  inclick btn:
    (count) == (count) - 1
    set t.1 "Count: (count)"

📋 Full Cheat Sheet

### BTW
title :      → page title
t.1 – t.6    → headings
p            → paragraph
btn          → button
img: / vid: / mus:   → media
a "text" -> url     → link
[id:N]       → id for MTWC
link web.stw / web.mtwc  → connect files

### STW
SYNTAX:   [prop:value]
MULTIPLE: [a:v],[b:v]
LEVELS:   1.1 → f.s · 1.12 → f.si · 1.13 → f.siz
KEY:      c · b.col · f.fa · f.si · t.al · m.to · p · b.ra

### MTWC
CONNECT:  btn.id = 1 , connect to 'web.btw':
ACTIONS:  action / run / stop / repeat / loop / wait
EVENTS:   inclick / inload / inhover / intype / insubmit
LOGIC:    if / else if / else / and / or / not
STATE:    var x = 0 · (x) == 5 · (x) == (x) + 1
OUTPUT:   show / alert / set / hide / reveal
STYLE:    theme dark / light · class add / remove

Note about the IDE: the WebLang IDE runs a working subset of the language in your browser: BTW structure and text tags, the STW translation table, and MTWC basics (actions, inclick / inload / inhover, if / else, variables, theme, set / hide / reveal, counters). New tags from this spec get added over time.
