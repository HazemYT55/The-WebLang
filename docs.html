🎨 STW · Style The Web

Extension: .stw · Replaces: CSS · Purpose: styles BTW elements using short property tags. Connect it with link web.stw in your .btw file.

The Rule · One Shortcode Per Property (v1.1)

Every CSS property has exactly one official STW shortcode. No levels, no clashes. Older shortcodes such as f.s, b.col or b.ra still work in the IDE, but it warns you and shows the official one to use.

🆕 New in v1.1

These features now work in the IDE and in converted files.

Read form data (MTWC)

form [id:1] {
  input email [id:4]
  btn "Login" [id:3]
}
t.1 "Welcome" [id:6]
btn.id = 3 , connect to 'page.btw':

action(Login)
  inclick btn:
    if get input.4 == "":
      alert "Type your email first"
    else
      set t.1 "Welcome, {get input.4}!"
      clear form.1

Multi-page sites

# page1.btw
a "Next page" -> page2.btw

# web.mtwc
action(Next)
  inclick btn:
    save name to 'page2'
    go 'page2.btw'

# page2's MTWC
action(Hello)
  inload page:
    load name from 'page2'
    set t.1 "Hello, (name)"

Convert each page and save it as its own file, for example page2.html. Links to .btw pages become .html links.

Open files in the IDE

Press Open files or drag files for any of the 10 languages (plus .md, .txt, .glb, images and media) onto the IDE. Each file gets its own tab and the page runs. Press Convert to get the HTML, CSS and JS files to download. If a file cannot be opened, the message under the editor says why and lists the endings that work.

Project files and new files

Every file you have is a tab above the editor: WebLang files, .md and .txt files, and media. Click a tab to edit or preview it, click × to close it. Text files are saved in this browser. Images, videos and models must be opened again after a reload.

Press + next to the tabs, type a name with its ending, for example page.btw, and press Enter. You get a blank file. The ending decides the language: .btw .stw .mtwc .iotw .motw .ifw .smdf .stf .3ds .ssitw, or .md and .txt. A name without an ending, or with an unknown one, shows a message instead of creating the file.

Preview: click an image, video or audio tab to see or play it. 3D models (.glb) are drawn by a .3ds scene. Your WebLang and text files are saved in this browser, so they are still there after a reload. Images, videos and models must be opened again after a reload.

🧩 The other 7 languages in the IDE

Each has its own tab with an example (press Load example). Converted sites export index.html, style.css, script.js, plus image.svg when you use IFW.

IOTW · data.iotw

(Name : [act:S] , Age : 13)
(profile : (Role : "Dev"))

Builds window.DATA. Write {Name} or {profile.Role} in BTW text and it fills in when the page runs. [act:S] runs action(S) from MTWC and stores its S.Name value. An action may have no event line.

MOTW · server.motw

make it (PHP)
make var(1) = show_img "a.png"
make var(2) = show_text "Welcome"

No PHP runs in the browser. The IDE turns each make var(N) into BTW lines at convert time, ordered by N (a repeated N: the later one wins).

IFW · image.ifw

circle: r=40 c=blue
text: "W" x=35 y=50 c=white

Draws an inline SVG and exports image.svg. Shapes without x and y sit left to right, bottom aligned. Use img: image.ifw in BTW to place it, otherwise it goes at the end of the page.

SMDF · docs.smdf

theme dark
show readme.md [toc] [code] [tables] [links]

Shows a Markdown file in the page. There is no disk, so open the .md file with Open files (or use the sample readme.md tab). Each option turns that feature on.

STF · viewer.stf

font mono
size 14px
show notes.txt [wrap] [scroll] [linenums]

Shows a text file with font, size, color, bg, maxw, wrap, scroll and line numbers. Same file rules as SMDF.

3DS · scene.3ds

scene {
  plane: w=500 h=500 c=gray
  cube: size=100 c=red [spin]
  light: sun
  camera: orbit
}

Built with three.js loaded from the internet, so it needs a connection and WebGL. Models (.glb / .gltf) come from the files list. A scene without a light or camera gives a warning.

SSITW · deck.ssitw

slide 1 {
  title "Welcome"
  text "My presentation"
}

Makes a slide deck with Prev / Next buttons and arrow keys. Style slides in STW with slide id = 1 ([bc:red]).

link web.mtwc

📋 Full Cheat Sheet

### BTW
title :      → page title
t.1 – t.6    → headings
p            → paragraph
btn          → button
img: / vid: / mus:   → media
a "text" -> url  or  a "text" href="url"  → link
[id:N]       → id for MTWC
link web.stw / web.mtwc  → connect files

### STW
SYNTAX:   [prop:value]
MULTIPLE: [a:v],[b:v]
RULE:     one official shortcode per property (v1.1)
KEY:      c · bg · bd · f.f · f.si · f.st · t.a · m.t · p · b.r · sh

### MTWC
CONNECT:  btn.id = 1 , connect to 'web.btw':
ACTIONS:  action / run / stop / repeat / loop / wait
EVENTS:   inclick / inload / inhover / intype / insubmit / inchange / inkey
FORMS:    get input.id · get form.id · clear input.id · clear form.id
PAGES:    go 'page2.btw' · back · reload · open 'url' · save x · load x
LOGIC:    if / else if / else / and / or / not
STATE:    var x = 0 · (x) == 5 · (x) == (x) + 1
OUTPUT:   show / alert / set / hide / reveal
STYLE:    theme dark / light · class add / remove
