BTW · STW · MTWC

The web, rewritten in 3 simple files

WebLang replaces HTML, CSS and JavaScript with three clean, readable file types you can learn in minutes.

Try the IDE Read the Docs

Three files. That's the whole language.

Each one does the job of a classic web technology, with a fraction of the syntax.

📄 BTW

replaces HTML

Structure and content. Headings, buttons, forms, layouts and media in short, readable lines.

.btw

🎨 STW

replaces CSS

Styling with short property tags. [b.col:black] instead of background-color: black.

.stw

⚡ MTWC

replaces JavaScript

Logic and interactivity. Events, variables and actions in plain words: inclick btn:

.mtwc
